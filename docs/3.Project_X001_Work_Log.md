The Home_X001 dataset was added after the supervisor's 2026-06-08 email. The dataset contains two device folders:

* `LEFT_WRIST`
* `RIGHT_WRIST`

Although the folder names refer to wrist position, the metadata indicates that these should be treated as two devices/participants for this exploratory comparison:

| Folder | Subject type | Device position |
|---|---|---|

* check whether the data are usable
* inspect RSSI, step count, and accelerometer patterns
* compare the two devices over their shared time period
* prepare the dataset for later algorithm testing if reference labels become available

## RSSI Processing

The script uses `SAMPLES_tags.csv` as the raw RSSI source. It reads:

* `timestamp`
* `uuid`
* `rssi`
* `info_other_tags`

The main `uuid` RSSI reading is kept, and additional simultaneous beacon readings from `info_other_tags` are also parsed. Beacon IDs are mapped to rooms using `metadata_subject.json` when an active metadata mapping is available.

Unmapped or external beacon IDs are not forced into a room label. They remain marked as unmapped/external signal sources.

The 10-minute RSSI features include:

* strongest beacon
* strongest mapped location
* strongest beacon proportion
* strongest-second RSSI gap
* total RSSI sample count
* RSSI confidence score

## Movement Processing

Step count is converted into step increments and summarised in 10-minute windows.

HE_ACC is processed in chunks to avoid loading the full accelerometer file into memory at once. The script calculates:

* acceleration magnitude mean
* acceleration magnitude standard deviation
* acceleration range
* accelerometer sample count

The accelerometer standard deviation is used as a simple movement intensity measure.

## Interpretation

The two devices have a long shared recording period, so the dataset is usable for descriptive comparison.

The right-wrist device has a longer recording duration and more RSSI detections than the left-wrist device. During the shared period, the two devices do not often have the same strongest beacon or mapped location. This is expected because they represent two people/devices rather than two sensors on the same person.

The movement features show moderate similarity rather than strong synchrony. Step count, accelerometer movement intensity, and RSSI confidence have correlations around 0.33 to 0.37. This suggests that the two devices sometimes share broad household routines or environmental context, but they should not be assumed to have identical location or movement patterns.

The most useful next use of this dataset is not to measure reference-based performance, but to test whether the RSSI + movement workflow behaves sensibly on a dataset with two devices and no reference labels. It can help identify:

* periods where both devices have stable RSSI
* periods where one device has much clearer RSSI than the other
* possible shared-location periods
* possible separation periods
* whether step count and accelerometer features help interpret RSSI confidence

## Current Conclusion

Home_X001 is suitable for exploratory RSSI and movement analysis, but not for supervised evaluation.

For this dataset, the right next step is to treat the strongest RSSI mapped location as a descriptive location estimate and attach confidence information from RSSI stability and movement features. If independent reference labels become available later, the same 10-minute feature table can be reused for formal method comparison.
