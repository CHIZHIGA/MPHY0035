# 可穿戴传感器与环境信标融合：居家行为分析项目

## 项目概览

本项目探索如何将腕戴设备记录的运动数据与家庭内蓝牙低功耗（BLE）信标的 RSSI 信号结合，用于估计使用者所在房间，并进一步描述睡眠、外出、房间转换、楼层活动及两人共处等居家行为。项目面向真实世界数据：不同数据集提供的传感器、元数据和参考标注并不一致，RSSI 还会受到人体遮挡、多径传播、信标位置和数据缺失的影响。

我最终设计并实现了一套统一的 Python 分析管线，使不同数据条件下的记录能够使用同一套状态定义和审计规则进行处理。其核心原则是：**RSSI 提出房间位置，运动与行为情境决定该结果应被保留、稳定、约束，还是保持未解析。**

## 我解决的问题

早期分析主要针对单个数据集分别设计规则。虽然专用方法能够利用特定数据的特点，但难以迁移，也不便于比较。为此，我将多轮探索整合为一套可复用框架：先检查每个数据集具备哪些输入能力，再将所有可用传感器对齐到五分钟时间轴，并始终保留原始推断、修正结果、修正原因和证据来源。

| 管线环节 | 主要处理 | 设计目的 |
|---|---|---|
| 数据能力审计 | 检查 RSSI、ACC、步数、压力、房间映射、第二位参与者和参考标注 | 仅启用有证据支持的分析分支 |
| 统一时间轴 | 标准化时区并聚合为五分钟窗口 | 对齐不同采样率和传感器格式 |
| 房间初始估计 | 计算各信标平均 RSSI，以最强信号提出原始房间 | 保留透明、可解释的基线 |
| 运动状态识别 | 优先使用 ACC 幅值波动，缺失时使用步数；自动选择聚类数量 | 识别低运动状态，不依赖统一的人工阈值 |
| 睡眠与占用推断 | 全天识别持续低运动片段，并区分睡眠、可能外出和未知状态 | 避免将行为或缺失直接伪装成房间 |
| 情境化修正 | 睡眠期间使用房间证据稳定结果；清醒期间按运动程度选择 RSSI 时间窗口 | 减少不合理跳变，同时避免过度平滑 |
| 可选分析 | 压力楼层约束、两人共处、参考标注比较 | 在统一框架下扩展不同数据场景 |

## 关键工程设计

- **显式处理缺失数据：**清醒期间没有 RSSI 时不进行插值；只有睡眠片段前后房间证据一致时，才填补短缺口。
- **允许算法拒绝作答：**运动、睡眠、外出或压力聚类未达到证据条件时，输出保持 `Unknown` 或 unresolved，而不是强制分类。
- **按记录自适应：**不同设备和佩戴方式会产生不同运动尺度，因此使用对数空间聚类为每段记录独立确定低运动边界。
- **保留推断来源：**最终时间轴将 room、behaviour 和 occupancy 分列保存，并记录每次修正来自睡眠稳定、运动自适应窗口、压力约束或缺口恢复。
- **配置与算法分离：**数据路径、时区、信标映射和可选功能写入配置文件，公共算法不包含数据集专用路径或隐藏规则。

## 量化结果

统一管线覆盖了全部可解析数据，而不是只选择表现较好的案例。

| 指标 | 结果 |
|---|---:|
| 成功处理的数据集合 | 10 |
| 参与者记录 | 13 |
| 五分钟窗口 | 25,513 |
| 对应记录时长 | 约 2,126.1 小时 |
| 管线运行失败 | 0 |
| 识别出的主要睡眠片段 | 61 |
| 可能外出片段 | 158 |
| 相对原始最强 RSSI 被修正的窗口 | 579 |
| 有双侧证据支持的睡眠缺口恢复 | 57 个窗口（285 分钟） |
| 房间转换次数 | 3,353 → 2,961（下降 11.7%） |
| 加权房间覆盖率 | 76.48% → 76.70% |

覆盖率只小幅增加是刻意设计的结果：管线不会通过填补清醒期间的未知位置来制造更完整的数据。房间转换减少也只代表时间稳定性提高，并不能单独证明定位更准确。

在四个带参考标注的数据集中，修正后的结果均提高了端到端一致性；同时，我分别报告覆盖率、条件准确率、平衡准确率和 Macro-F1，避免用单一指标掩盖未知窗口或类别不平衡。

| 数据集 | 平衡准确率（原始 → 修正） | 端到端一致性（原始 → 修正） |
|---|---:|---:|
| DH Paris | 48.4% → 67.0% | 28.1% → 61.9% |
| DH PanoH | 54.6% → 66.0% | 56.3% → 89.6% |
| DH Strad | 49.8% → 69.2% | 57.9% → 82.0% |
| KM Mal | 60.2% → 81.2% | 57.1% → 85.8% |

这些结果是与现有参考标注的一致性，而不是绝对的“真实位置准确率”。部分规则也在查看标注结果后得到完善，因此仍需要在独立数据集上冻结规则并进行验证。

## 代表性案例

- **EF-001：**针对睡眠期间不合理的房间频繁切换，统一方法将转换次数从 693 降至 556，同时保留原始信号和每次修正的来源。
- **EF-002：**在睡眠期间存在 RSSI 遮挡时，仅恢复前后房间证据一致的 51 个五分钟缺口；缺乏支持的长缺失段继续保持未知。
- **NewData80h：**自动压力分组识别出两层环境，但只有通过物理分离度和稳定性检查后，压力信息才可约束 RSSI 候选房间。
- **Home_X001：**两位参与者分别完成位置推断后才进行共处分析；由于没有独立位置标签，结论仅作为描述性行为证据。

## 我的贡献

我独立完成了从数据审计、传感器对齐和特征设计，到算法实现、跨数据集运行、结果评估和可视化的完整流程。技术栈以 Python 为主，使用 pandas 和 NumPy 处理时间序列，使用 scikit-learn 完成 KMeans 聚类及轮廓系数审计，并通过 JSON 配置、命令行入口、测试和跨数据集汇总提高复现性。

开发过程中我也使用了 AI 辅助工具进行代码草拟、调试和文档整理，但对生成内容进行了路径、字段、原始数据、审计文件和量化结果的逐项核查。科学解释、算法取舍和验证边界由我负责确定。

## 项目价值与反思

这个项目的重点并不是为某一个数据集获得最高分，而是在传感器缺失、标签有限和家庭条件不同的情况下，建立一套可迁移、可审计且知道何时不应作答的方法。与高度定制的算法相比，统一方法可能牺牲部分数据集上的最优表现，但换来了共同的数据结构、明确的失败状态、可追溯的修正过程，以及对睡眠、外出、楼层和共处等 lived experience 信息的一致表达。

下一步工作是冻结当前规则，在未参与开发的新家庭和新参与者数据上进行独立验证，并将房间、占用、睡眠、楼层和共处结果分别与观察、时间戳日记及参与者反馈进行比较。
