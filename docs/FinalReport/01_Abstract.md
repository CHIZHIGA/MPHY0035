# 1. Abstract

Understanding daily function at home requires activity data to be interpreted within spatial, behavioural, and household context. This project developed an auditable five-minute pipeline combining wearable movement data with Received Signal Strength Indicator measurements from environmental Bluetooth Low Energy beacons. The framework processed 13 participant-sessions from ten collections, using strongest RSSI as a transparent location proposal while movement, sleep, away state, missingness, and optional pressure evidence determined whether estimates were retained, stabilised, constrained, or left unresolved.

Across 25,513 windows, the pipeline changed 579 room estimates and reduced observed room transitions by 11.7%, while weighted room coverage increased only from 76.48% to 76.70%, reflecting conservative missing-data handling. It identified 61 main-sleep episodes and 158 probable-away runs. Corrected end-to-end agreement exceeded raw agreement in all four datasets with reference annotations, although earlier dataset-specific methods retained stronger balanced room agreement in several comparisons.

The main contribution is therefore a common, interpretable representation of room, behaviour, occupancy, correction provenance, and optional sensor context across heterogeneous datasets. However, some rules were refined using the labelled collections, and no independent labelled test set was available. Co-presence and other no-reference behavioural outputs should consequently be interpreted as descriptive evidence rather than verified clinical outcomes.
