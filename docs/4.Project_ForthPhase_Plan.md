## Planned Work for Point 3: Time Together and Apart

The first main analysis task is to estimate co-presence states over the shared recording period.

The workflow should:

1. Build a shared 10-minute timeline for SUBJECT and STUDY_PARTNER.
2. Estimate each person's location from RSSI-derived mapped location.
3. Attach an RSSI confidence score to each location estimate.
4. Classify each time window into one of the together/apart states.
5. Summarise total time and percentage of time in each state.

The main output metrics should include:

* total shared analysis duration
* total time both in home
* total time both away
* total time one in home and one away
* total time in same estimated location
* total time in different estimated locations
* same-location time by room
* daily and hourly patterns of co-presence

The interpretation should clearly state that these are RSSI-derived co-presence estimates, not manually verified labels.

## Planned Work for Point 4: Location Algorithm Comparison

The second main analysis task is to compare different location estimation algorithms.

### A. Fixed-Window Strongest Beacon Methods

The first method should estimate location using the strongest beacon in fixed time windows.

Window lengths to compare:

* 5 minutes
* 10 minutes
* 30 minutes

For each window, calculate:

* strongest beacon
* mapped location from metadata
* strongest beacon proportion
* strongest-second RSSI gap
* total RSSI sample count
* RSSI confidence score

### B. Movement-Adaptive Window Methods

The second method should use movement to adapt the location-estimation window.

The basic idea is:

* use longer windows during low movement
* use shorter windows during higher movement

Step-count thresholds to test:

* stationary if steps <= 1
* stationary if steps <= 2
* stationary if steps <= 5
* stationary if steps <= 10

This follows Derek's suggestion that the window length can depend on movement.

The output should compare how different thresholds affect:

* location stability
* number of transitions
* RSSI confidence
* co-presence state estimates

### C. Low-Motion RSSI Clustering

The third method should explore automatic clustering.

The intended workflow is:

1. Identify low-motion windows using step count and/or accelerometer movement intensity.
2. Use RSSI features from those low-motion windows to learn distinct signal clusters.
3. Interpret clusters using their dominant beacon and metadata-mapped location.
4. Apply the cluster model to the full timeline, including movement periods.
5. Generate an estimated location/cluster timeline for each person.

This method should be described as exploratory because the clusters are not ground-truth rooms. They are RSSI-derived signal states that may correspond to locations.

### Comparison Strategy

Since Home_X001 has no independent reference labels, the methods should not be compared using accuracy.

Instead, compare:

* agreement between methods
* timeline stability
* transition frequency
* confidence score distribution
* consistency of co-presence summaries
* whether movement-aware methods reduce noisy location switching

## Planned Work for Point 5: Integrated Timeline Visualisation

The visualisation should show:

The goal is to make it possible to visually inspect:

This figure should be suitable for supervisor review and later report use.
