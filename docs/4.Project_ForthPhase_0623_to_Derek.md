These figures are descriptive visualisations of RSSI-derived estimates. The X001 dataset does not include independent validation labels, so the interpretation focuses on stability, agreement, movement context, and visual consistency.

## Algorithm Explanation

### 4a fixed-window RSSI

The 4a method is the RSSI-only baseline.

For each fixed time window, the algorithm:

1. groups RSSI samples into 5-minute, 10-minute, or 30-minute windows
2. identifies the strongest beacon in each window
3. maps that beacon to a room/location using the metadata mapping
4. compares SUBJECT and STUDY_PARTNER estimated locations to derive co-presence state

This method is simple and directly interpretable. The main trade-off is window length: shorter windows show more short-term changes, while longer windows are smoother.

Supporting figure from the previous analysis:

![Fixed RSSI window co-presence comparison](../Results/X001/ForthPhase/X001_forthphase_fixed_rssi_window_copresence_comparison.png)

### 4b step-adaptive RSSI

The 4b method combines movement and RSSI. RSSI remains the spatial signal, while step count controls how much RSSI evidence is grouped together.

The step-adaptive rule is:

```text
if 30min steps <= 10:
    use 30min RSSI
elif 10min steps <= 10:
    use 10min RSSI
elif 5min steps <= 10:
    use 5min RSSI
else:
    use 1min RSSI
```

This means low-motion periods can use longer RSSI windows, while more active periods use shorter RSSI windows. Movement is not used to directly assign a room label; it is used to choose the RSSI window length.

Supporting figure from the previous analysis:

![4b adaptive window distribution](../Results/X001/ForthPhase/X001_forthphase_hierarchical_step_adaptive_window_distribution.png)

### 4c low-motion RSSI clustering

The 4c method is an exploratory RSSI-vector clustering method.

The algorithm:

1. selects low-motion windows using `30min steps <= 10`
2. builds 30-minute RSSI vectors from mapped home beacons
3. trains a clustering model separately for SUBJECT and STUDY_PARTNER
4. applies the learned clusters to all 30-minute windows with RSSI evidence
5. interprets each cluster using its dominant mapped location

This method is useful for finding repeatable RSSI signal states. However, a cluster's dominant mapped location is not the same thing as a direct strongest-beacon room estimate at every timestamp.

## 4c Clustering Limitation and Diagnostic

Derek noted that some periods appear different between algorithms, for example when 4b gives an unmapped/grey period while 4c gives a Bathroom-like result for STUDY_PARTNER.

After checking the data, my interpretation is that this mainly reflects a limitation of the 4c clustering method rather than a simple plotting issue.

The key difference is how the two algorithms assign location:

```text
4b:
step count -> choose RSSI window length
selected window -> strongest beacon / mapped location

4c:
RSSI vector -> learned cluster
cluster -> dominant interpreted location
```

Therefore, 4b is a more direct window-level RSSI estimate, while 4c is a learned signal-state interpretation.

In the plots, grey should be interpreted as:

```text
away / unmapped / no mapped location estimate
```

It should not always be interpreted as complete absence of beacon visibility. The diagnostic table shows cases where 4b gives `Unmapped`, but the same 30-minute period still contains RSSI samples. In those cases, 4c may assign the RSSI vector to a learned cluster whose dominant interpreted location is Bathroom.

The diagnostic output is saved here:

```text
X001_0617_grey_to_blue_diagnostic.csv
```

The current diagnostic found 59 STUDY_PARTNER windows where:

```text
4b location = Unmapped
4c cluster location = Bathroom
4c has RSSI evidence = True
```

This suggests that 4c may over-generalise some ambiguous RSSI patterns into a dominant Bathroom-like cluster, especially for STUDY_PARTNER. This does not necessarily mean that 4c is wrong as a clustering method; it means that the clusters are better interpreted as repeated RSSI signal states rather than direct room-level location labels.

For this reason, I would treat 4c as exploratory rather than the main location method. A possible future improvement would be to add an ambiguity check, or require consistency between the cluster-derived location and the current strongest-beacon location before assigning a room label.

## Overall Interpretation

The updated multi-day figures make the comparison clearer.

4a remains a useful RSSI-only baseline. The 5-minute, 10-minute, and 30-minute versions mainly differ in temporal smoothness.

4b is currently the strongest main method because it combines movement and RSSI in an interpretable way. Step count controls the RSSI window length, while RSSI still determines the spatial estimate.

4c is useful for exploratory RSSI signal-state analysis, but it should not be treated as the preferred room-level location method. Its cluster locations can be dominated by broad learned signal patterns, which may explain some of the visual differences from 4a and 4b.
