## Derek Point 4: Check Co-Presence Consistency With Location Lines

### Status

Checked.

### Current Understanding

Derek pointed out that, in one 4a fixed 30-minute RSSI example, the co-presence line did not appear consistent with the SUBJECT and STUDY_PARTNER location lines.

I checked this again. The co-presence calculation itself appears to be consistent with the estimated location lines.

For the example Derek highlighted, the issue is that the 4a fixed 30-minute RSSI method sometimes estimates the SUBJECT as being in a non-bedroom location during the night/sleep period. This appears as bedroom/bathroom or other short location changes in the SUBJECT line.

Because co-presence is calculated directly from the two estimated location lines, those SUBJECT mis-labellings then cause the co-presence line to show a long period of:

```text
Different locations
```

This is expected from the calculation: if STUDY_PARTNER is estimated as Bedroom, but SUBJECT is estimated as Bathroom or another room, then the derived co-presence state should be `Different locations`.

The colour interpretation is:

```text
green  = Same location
orange = Different locations
blue   = SUBJECT home only
purple = STUDY_PARTNER home only
grey   = Both away/unmapped
```

In the highlighted section, the co-presence line is mainly orange, so it is already showing that the algorithm estimates the two people as not being in the same location.

The conclusion is that Derek is right that the 4a fixed 30-minute RSSI method mis-labels some SUBJECT night-time location segments. However, the co-presence line is reflecting that mis-labelling correctly. The problem is therefore the underlying 4a room estimate during that period, not the co-presence calculation.

## Point 6: New Idea - Hybrid 4b + 4c Location Algorithm

### Aim

This is my new idea after reviewing the 4b and 4c results.

The issue with the previous 4c method is that the clustering model was trained only on low-motion windows, but it was then applied to all time periods. This is not ideal because high-motion or transition periods may have RSSI patterns that are different from the stable low-motion training data.

The revised hybrid approach is:

```text
Use 4b step-adaptive RSSI as the main location estimate.
Use 4c clustering only as a conditional override during stable low-motion windows.
```

### Decision Rule

The hybrid method uses the following rule:

```text
base_location = 4b step-adaptive RSSI location

if selected_window == 30min
and cluster_location is not Unmapped/Out
and cluster training windows >= 10
and cluster mean strongest-second gap >= 8
and 4b RSSI evidence is weak or ambiguous:
    final_location = cluster_location
else:
    final_location = base_location
```

In plain terms, this means:

```text
Trust 4b by default.
Only allow 4c to override 4b during stable low-motion periods.
Only override when 4b is weak or ambiguous.
Do not override when 4b has clear RSSI evidence.
```

Weak or ambiguous 4b evidence is defined as:

```text
4b strongest-second gap < 5
or 4b location is Unmapped/Out
or 4b RSSI sample count == 0
```

If 4b has strong RSSI evidence:

```text
4b strongest-second gap >= 8
```

then 4b is kept even if the cluster gives a different location.

The purpose of this rule is to avoid the previous 4c problem. The cluster model is trained on low-motion RSSI windows, so it should not be allowed to relabel high-motion or transition periods. In the hybrid method, 4c is only a conservative support component, not the main estimator.

### Interpretation

The hybrid method fixes the main conceptual problem with 4c: clustering is no longer used as an all-time location estimator.

However, the current evidence does not show improvement over 4b:

* X001 has no reference labels, so the hybrid method can only be assessed by stability and agreement.
* The four labelled datasets have reference labels, and hybrid accuracy is the same as 4b in all four.
* The conservative override rule rarely activates, because either the 4b RSSI evidence is already strong or the cluster profile is not reliable enough.
* The cluster-only method is still weaker than 4b in balanced accuracy.

The current conclusion is therefore:

```text
4b step-adaptive RSSI remains the main method.
4c clustering can be tested as a conservative low-motion support component.
There is not yet evidence that hybrid 4b + 4c improves room-level location accuracy.
```
